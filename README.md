# Marinara Pets

Marinara용 시메지 개인 확장 모음입니다.

## 포함 확장

### 🦫 끄버
비버형 시메지 확장입니다.

- 화면 위에서 이동 / 휴식 / 수면
- 쓰다듬기, 먹이 주기, 잡아들기
- 기존 콘보방에 기반한 간단한 대사
- Marinara 환경에 맞춘 경량 동작

### 🐇 끄끼
토끼형 시메지 확장입니다.

- 화면 위에서 이동 / 휴식 / 수면
- 쓰다듬기, 당근 먹이기, 잡아들기
- 커피 / 출근 등 추가 행동
- 기존 콘보방에 기반한 간단한 대사


## 주의

마리나라 v2.5.0 에서 만든 개인 제작 확장입니다.  
Marinara 버전 변경에 따라 일부 기능이 동작하지 않을 수 있습니다.
